Sarasa UI J/K 배포 검토 (2026-10-16)
==================================

배포 폰트는 Sarasa UI J Regular 및 Sarasa UI K Regular v1.0.42 두 개뿐입니다.
기존 Sarasa UI J v1.0.10을 교체하고 K를 추가했습니다.
나눔·마루부리 등 나머지 번들 폰트와 해당 개별 고지는 제거했습니다.
고양덕양체와 한글누리체도 배포 대상에서 제외되어 있습니다.

두 TTF는 공식 릴리스 원본 그대로입니다. 아카이브 SHA-256을 공식 SHA-256.txt와
대조했으며, payload 및 archive 해시는 fonts.csv와 provenance.csv에 기록했습니다.
각 개별 고지에 내장 저작권과 해당 버전 LICENSE 전체를 보존했습니다.
Renzhi Li, Inter, Adobe, Google의 저작권 및 Adobe 'Source' Reserved Font Name을
유지합니다. 폰트는 SIL OFL 1.1이며 모드 코드의 MIT로 재허가되지 않습니다.
소프트웨어 동봉/재배포 시 저작권과 OFL 전문을 포함하고, 글꼴 자체를 단독 판매하지
않으며, 수정 시 Reserved Font Name 등 OFL 조건을 준수해야 합니다.

J/K는 각각 일본식/한국식 지역 자형입니다. 두 Regular 파일의 cmap 검사 결과:
현대 한글 완성형 11,172/11,172, 기본 CJK 통합 한자 20,992/20,992,
CJK 확장 A 6,592/6,592, 일반 히라가나 86/86, 일반 가타카나 90/90.
CJK 확장 B는 2,109/42,720으로 모든 희귀 한자를 포함하지 않습니다.
이는 문자 매핑 검사 결과이며 게임 내 시각 검증 결과는 아닙니다.
