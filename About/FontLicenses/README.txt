Bundled font licensing records
=============================

The mod bundles only Sarasa UI J Regular and Sarasa UI K Regular, version 1.0.42.
Both use SIL Open Font License 1.1. Each *.ttf.LICENSE.txt contains the exact font's
embedded copyright, publisher/source links, SHA-256 and full upstream license.
fonts.csv maps both payloads to their notices, versions, sizes and SHA-256.

Ship Fonts/ together with this whole directory and retain the corresponding notices
when copying a font separately. The mod's MIT license does not replace the OFL.
Do not sell fonts by themselves. Preserve copyright/license notices and OFL terms;
modified fonts must comply with the Reserved Font Name conditions.

Verified on 2026-10-16. Both TTFs are byte-identical to the official v1.0.42 archives.
provenance.csv records the archive URLs, SHA-256 hashes and archive entries.
Archive hashes were checked against the official release's SHA-256.txt:
https://github.com/be5invis/Sarasa-Gothic/releases/download/v1.0.42/SHA-256.txt
REVIEW.txt summarizes the bundled set and coverage limits.
