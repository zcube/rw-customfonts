Font-only expansion example verification (2026-10-18)
===================================================

Example: Examples/ABeeZeeFontPack
Package: zcubekr.customfonts.example.abeezee
Payloads: unmodified ABeeZee Regular and Italic; SIL OFL 1.1.
Original copyright, full OFL and pinned upstream hashes ship with the example.

Build and non-game tests
-----------------------
PASS: task build, all four release configurations (1.4, 1.5, 1.6, 1.7).
1.4 retains three existing obsolete Widgets.HorizontalSlider warnings.
PASS: task test, 177 assertions, including the actual example payloads.
The example checks dependency/loadAfter XML, no assemblies, supported versions,
fixed upstream revision/hashes/notice text, two style registrations, Unity primary/
fallback import bytes and file content cache reuse. Synthetic cases also check
content-root priority, recursive TTC discovery, corrupt siblings, duplicate faces,
package separation and stable selections after a display-name change.

not a current Harmony limitation: Harmony 2.4 added Apple Silicon ARM64 support

--mac-arch x86_64 (Task: MAC_ARCH=x86_64) remains available for legacy testing.
The earlier result must not be read as evidence against native support in 2.4+.

Runtime assertions
------------------
- Actual LoadedModManager order, two package-scoped bundle keys, both styles.
- Font-only packs count as loaded content without dummy Defs or a DLL.
- Display label includes the actual pack name.
- Unselected styles stay unloaded; manual/OS discovery and folder recursion can
  all be disabled without hiding the pack.
- Native UI glyph rasterization in Tiny/Small/Medium for Regular and Italic.
- TMP glyph quads and the selected font binding on visible live world labels.
- All four target fallback lists resolve the actual example font bytes.
- Refresh retains choices and a consistent catalog; restart retains primary and
  fallback settings and renders the same example fonts.
- An active pack before Custom Fonts and a disabled pack register no pack fonts.

Limitations
-----------
Live 1.4/1.5, Windows and Linux were not run here; those are not claimed as
live-game passes. 1.4/1.5 compile successfully and use the same Unity adapter.
ABeeZee is a Latin font, not a Hangul/CJK coverage test. The fallback checks
verify source bytes, renderer setup and rendering, not every missing-codepoint
fallback choice. GUI integration requires a desktop and installed game/Harmony.
Wrong-order negative runs can produce the expected empty-content diagnostic:
these packs are deliberately outside the supported load order.
Large raw engine logs and test profiles stay outside Git; pass markers are
recorded below. Rerun with a fresh --output directory to obtain new raw evidence.
